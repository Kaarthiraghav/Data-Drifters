## What This App Does

A web application that allows business users to explore outlet-level sales potential predictions for January 2026 across 20,000 traditional trade outlets in Sri Lanka. Built for the Data Storm v7.0 Final Round.

**Features:**
- Browse outlet-level predictions across the full dataset
- Filter by province and distributor
- Drill into any outlet to view predicted potential, key drivers, and AI-generated reasoning
- Explore the LKR 5M Western Province budget allocation

## Setup Instructions

### 1. Prerequisites
- Python 3.8 or higher
- pip

### 2. Clone / Download the project
```bash
cd Data-Drifters
```

### 3. Create and activate virtual environment
```bash
# Create
python -m venv .venv

# Activate — Mac/Linux
source .venv/bin/activate

# Activate — Windows
.venv\Scripts\activate
```

### 4. Install dependencies
```bash
pip install streamlit pandas numpy plotly folium streamlit-folium requests
```

### 5. (Optional) Set OpenRouter API key for live AI explanations
```bash
# Mac/Linux
export OPENROUTER_API_KEY=sk-or-your-key-here

# Windows
set OPENROUTER_API_KEY=sk-or-your-key-here
```
Get a free key at https://openrouter.ai/keys

### 6. Run the app
```bash
cd app
streamlit run app.py
```

The app will open automatically at **http://localhost:8501**

## Data Requirements

The app reads from these files (already generated by the pipeline):

| File | Location |
|---|---|
| Predictions | `output/Data_Drifters_predictions.csv` |
| Gold features | `gold/outlet_features.csv` |
| Outlet coordinates | `silver/outlet_coordinates.csv` |
| Transaction history | `silver/transactions_clean.csv` |
| Budget allocations | `output/Data_Drifters_budget_allocations.csv` |
| AI explanations | `output/outlet_ai_explanations.csv` |

The app works without the last two files — it will use fallback rule-based explanations and zero budget allocation until those files are generated.
